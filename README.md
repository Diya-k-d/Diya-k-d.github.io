# Diya K D — Portfolio

A single-page portfolio site. No build step, no dependencies — just these files.

## Publish it free on GitHub Pages (about 5 minutes)

1. Go to https://github.com/new and create a repository named exactly:
   **Diya-k-d.github.io**
   (Public, no README needed.)
2. On the repo page, click **"uploading an existing file"** (or Add file → Upload files).
3. Upload everything in this folder: `index.html`, `styles.css`, and the `assets` folder
   (which holds your resume PDF). Commit the upload.
4. Wait about a minute, then open **https://Diya-k-d.github.io** — that's your live site.

Done. Share that link anywhere.

## Updating things later

- **StudyCompanion live demo link:** open `index.html`, find the line near the top that says
  `STUDYCOMPANION_URL = "..."` (there's a "QUICK EDIT" comment above it) and replace the URL.
- **Resume:** replace `assets/Diya_K_D_Resume.pdf` with a new PDF of the same name.
- **Any text:** edit `index.html` in GitHub's web editor (pencil icon), then Commit changes.

## Files

- `index.html` — all content and page structure
- `styles.css` — all styling
- `assets/Diya_K_D_Resume.pdf` — the downloadable resume
